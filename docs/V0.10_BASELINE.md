## 5. Architectural Invariant Summary Entering v0.10

1. **Zero Raw Shell Execution**: No arbitrary shell interpolation (`shell=True`, `os.system`, `Invoke-Expression`).
2. **Deterministic & Extensible Routing**: All user requests flow through `NLP -> StructuredUtterance -> Window Grounding -> ActionGate -> CapabilityRegistry`.
3. **Unconfigured Reasoning Provider**: The `ReasoningProvider` interface remains strictly unconfigured; no external LLM API dependency.
4. **Origin Window Grounding**: All window and UI interaction commands ground to the active origin HWND captured before `Alt+Space` steals focus.
5. **Reversibility Guarantee**: Destructive or positional operations remain reversible via undo stacks or explicit confirmation dialogs.
