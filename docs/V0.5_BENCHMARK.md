## 1. Executive Summary

AstraRun v0.5 transitions semantic routing from isolated, single-model shadow experiments (v0.3 Laya, v0.4 Kev) into a multi-model **Decision Fusion Engine** with statistical disagreement gating and deterministic entity resolution.

This benchmark evaluates 10 distinct routing configurations (B0 through B9) across identical holdout queries, comparing accuracy, safety (Safe False Abstention Rate and False Execution Rate), agreement dynamics, and latency.

### Primary Benchmark Invariant
$$\text{Production Safe Cascade (B9) False Execution Rate (FER)} \equiv 0.0\%$$
On all ambiguous, out-of-scope, or adversarial queries, the platform safely abstains to `unknown` with zero unintended tool invocations.

## 5. Comparative Analysis & Findings

### 5.1 Domain Adaptation Impact (B1 vs. B2)
- **Zero-Shot Generic Laya (B1)** achieved 39.5% accuracy with an unacceptable 8.3% False Execution Rate (FER) on out-of-scope and adversarial queries.
- **Domain-Adapted AstraRun-Laya (B2)** boosted top-1 accuracy to **53.0%** (+13.5% absolute gain) while slashing FER from 8.3% down to **0.8%** and boosting Safe False Abstention Rate (SFAR) from 3.3% to **52.5%**.
- Parameter-efficient head adaptation on frozen ModernBERT-large successfully tailored the model to desktop developer workflows without catastrophic forgetting.

### 5.2 Multi-Question Disagreement Gating Superiority (B6 / E5)
- Configuration **B6 (E5)** achieved the highest accuracy across the entire evaluation: **63.5%** (254 of 400 queries correct).
- Crucially, B6 achieved **100.0% SFAR** (120 of 120 unknowns safely rejected) and **0.0% FER** (0 unintended executions).
- Evaluating intent, ambiguity, and consequence risk simultaneously enables AstraRun to intercept dangerous queries (`rmdir /s /q`, `kill port 80`) and ambiguous requests (`open project`) before they ever reach the action registry.

### 5.3 Local Sovereignty vs. Cloud Reference (B6 vs. B8)
- External cloud reference judge **Jev System One (B8)** achieved 59.8% accuracy and 84.2% SFAR, but suffered a **5.8% False Execution Rate**.
- Local **Ensemble E5 (B6)** outperformed Jev in both accuracy (**63.5% vs. 59.8%**) and safety (**0.0% FER vs. 5.8% FER**).
- Furthermore, local routing preserves 100% data sovereignty with zero path or token leakage, validating the architectural decision to keep core decision routing on-workstation.

### 5.4 Production Safety Guarantee (B9)
- Configuration **B9 (Safe Cascade)** enforces deterministic routing as the primary gate and delegates unresolved queries to the E5 ensemble only when unambiguous and safe.
- It achieves **46.5% accuracy**, **100.0% SFAR**, and **0.0% FER** with mean latency under 0.1ms for deterministic hits.

   - Continue expanding the typed entity resolver to encompass running containers (Docker), Git branches, and VS Code workspaces.
