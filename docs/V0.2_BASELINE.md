## 3. Subsystem Architecture in v0.1

1. **Routing**: `DeterministicRouter` uses verb normalization (`open`, `launch`, `start`, `go to`, `show`, `goto`) and exact dictionary lookups against discovered apps, folders, and URL aliases. Returns typed `Decision`.
2. **Search / Suggestions**: Basic prefix-only matching (`startswith`) in `LauncherWindow._on_text_changed`. Max 5 items.
3. **Application Discovery**: Windows App Paths registry (`HKLM` / `HKCU`) + system `PATH` (`shutil.which`) + hardcoded fallback candidates. Caches 80+ apps.
4. **Folder Discovery**: Windows User Shell Folders via Registry (`HKCU`) resolving Downloads, Documents, Desktop, Pictures, Videos, plus Workspace and Active Projects.
5. **Hotkey**: Native Win32 `RegisterHotKey` (ID 101, `MOD_ALT | MOD_NOREPEAT`, `VK_SPACE`) on a dedicated `QThread` running Win32 `GetMessageW`. Emits `hotkey_pressed` Qt signal.
6. **UI**: PySide6 frameless, top-most, translucent window centered horizontally on the cursor's monitor.
7. **Tool Registry**: Risk-tiered execution (`LOW`, `MEDIUM`, `HIGH`, `BLOCKED`) strictly dispatching to `open_app`, `open_folder`, `open_url` with zero raw shell evaluation.

---

## 4. Key Limitations Targeted for v0.2

1. **Prefix-Only Matching**: No typo tolerance, no subsequence matching, no acronym resolution (e.g. `vsc` for VS Code fails, `notpad` fails).
2. **Suggestions UI**: Basic `QListWidget` with prefix filter; no Up/Down arrow selection while typing in input field; no category badges; no weighted ranking.
3. **App Discovery**: Start Menu (`.lnk` shortcuts in user and system programs) is not indexed, missing installed desktop software without explicit App Paths.
4. **Monitor Positioning**: Anchors exclusively to the cursor monitor rather than the user's currently focused foreground application window.
5. **No Routing Telemetry / Benchmark**: No local event dataset recording routing outcomes, no false-execution evaluation framework, no usage signals.
