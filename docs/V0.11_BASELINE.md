## 5. Invariants to Preserve in v0.11

1. **Strict Interaction Tiering**:
   - Tier A (Native Win32/WLAN/Power APIs) > Tier B (Structured Interfaces) > Tier C (UI Automation) > Tier D (Shortcuts) > Tier E (Vision fallback) > Tier F (Raw coordinates - PROHIBITED).
2. **Zero Raw Shell Execution**:
   - The agent planner must NEVER generate raw PowerShell or CMD strings to `os.system` or `eval`. All operations must select typed capability schemas with validated parameters.
3. **Execution Authority Boundary**:
   - Neural/semantic models propose plans; deterministic ActionGate and typed verifiers authorize and execute.
4. **Honest Task Progress**:
   - Live Task HUD V2 must report authentic progress modes (`INSTANT`, `DETERMINATE`, `INDETERMINATE`, `EVENT_DRIVEN`). Never display simulated or fake progress percentages.
5. **Non-Focus-Stealing HUD**:
   - The Live Task HUD must never steal focus from active user windows (`WS_EX_NOACTIVATE`, Qt `WA_ShowWithoutActivating`).
6. **Centralized Motion System**:
   - All HUD and Launcher animations must respect `MotionTokens` and system reduced-motion accessibility settings.
7. **Interactive Desktop Isolation**:
   - Processes launched for interactive desktop display must explicitly target `WinSta0\Default`.
