## 3. Subsystem Execution Breakdown

Measurements taken on local host (Intel Core i5-12450H, 16 GB RAM, RTX 2050):

### 3.1 Registry Dispatch Overhead
- `CapabilityRegistry.execute()` internal routing, schema validation, and error wrapping: **< 0.008 ms**.
- Adding an observation to `ObservationStore`: **< 0.002 ms**.

### 3.2 Operating System Capability Latencies
- **Application Discovery (`list_running_applications`)**: 0.85 – 1.40 ms (Win32 `EnumWindows` + title checks).
- **Window Discovery (`list_windows`, `foreground_window`)**: 0.45 – 1.10 ms.
- **Process Metrics (`inspect_process`, `process_resource_usage`)**: 0.35 – 0.90 ms (`psutil`).
- **Network Port Resolution (`inspect_port`, `find_process_on_port`)**: 0.28 – 0.65 ms.
- **File Metadata & Discovery (`find_file`, `file_metadata`)**: 0.15 – 0.85 ms (bounded traversal).
- **System CPU/Memory Status (`cpu_status`, `memory_status`)**: 0.12 – 0.35 ms.
- **Dedicated GPU Status (`gpu_status`)**: 2.50 – 5.10 ms (when invoking `nvidia-smi`), 0.05 ms fallback.
- **Workstation Session Lock (`lock_workstation`)**: 0.04 ms (`LockWorkStation` Win32 API).
