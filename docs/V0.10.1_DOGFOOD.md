## 1. Dogfooding Objectives & UX Scope

Following the discovery of the foreground lock failure on physical hardware, an intensive 45-minute resident dogfooding session was conducted to audit the actual user-facing experience:
1. **Real Alt+Space Summoning**: Verify that pressing `Alt+Space` reliably brings up the command bar across all applications, bypassing Windows 11 `LockSetForegroundWindow` via Win32 `AttachThreadInput`.
2. **Top-Center Floating Command Bar**: Verify smooth entrance drop-in (150ms `OutCubic`) and exit slide-up (110ms `InCubic`) animations, with instant focus into `input_field` and zero premature focus-loss dismissals.
3. **Decoupled Floating Task HUD**: Verify that ongoing background tasks display progress in the top-right corner without stealing keyboard focus from active target applications (e.g. Notepad, VS Code, Browser).
4. **The Real Notepad Gate**: Real-time end-to-end task handoff: summon launcher -> submit query -> launcher slides up -> focus returns to Notepad -> Task HUD renders progress -> keystrokes arrive without focus disruption.
5. **Resident Resource Stability**: Long-running stability across 50+ real invocations, verifying memory plateau, 0.0% idle CPU, and clean single-instance lifecycle management.
