## 5. Architectural Invariants to Maintain in v0.7

1. **Zero Raw Shell Execution**: Natural language text is never passed to PowerShell, CMD, or `subprocess(shell=True)`.
2. **Zero Autonomous LLM Control**: No autonomous agent loops, no cloud LLMs, no local reasoning models invoked.
3. **Reasoning Provider Boundary**: The `ReasoningProvider` interface and `ReasoningRequired` escalation flag remain intact but UNCONFIGURED.
4. **Read-Only First**: Capabilities default to discovery, inspection, and querying before any mutation or termination.
5. **0.00% FER & 0.00% Negation Leakage**: Existing benchmarks must retain 0.00% error rates.
6. **Preserve Baseline Tests**: All 126 existing automated unit tests must remain completely green.
