## 1. Security Architecture & Boundary Invariants

AstraRun enforces strict defense-in-depth principles:

1. **No Raw Shell Execution**:
   - Natural language commands are never passed directly to `powershell.exe`, `cmd.exe`, or `os.system(cmd)`.
   - All executions pass through the deterministic `ActionGate`, capability registry, and structured tool handlers.
2. **Hard Security Policy Enforcement**:
   - `_PROTECTED_PROCESSES`: Rejects any attempt to terminate critical system processes (`system`, `system32`, `lsass`, `csrss`, `services`, `svchost`, `wininit`, `winlogon`, `dwm`, `explorer`).
   - `_PROHIBITED_COMMAND_PATTERNS`: Rejects destructive operations (`format`, `rm -rf`, `del /s`, `shutdown`, `powershell -enc`).
3. **Zero OS Authority for Neural Models**:
   - Neither Laya nor spaCy has execution privileges. They emit structured intermediate representations (`StructuredUtterance`) that must be compiled and validated against capability schemas.
4. **Negation Safety**:
   - Negated clauses (`don't open notepad`, `do not click delete`) are explicitly flagged with `negated=True` and filtered out of executable proposals.
5. **Interactive Desktop Isolation**:
   - Win32 launches explicitly target `WinSta0\Default` via native `CreateProcessW` to prevent background DCOM server confusion or headless window starvation.
