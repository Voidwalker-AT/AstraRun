## 1. Problem Statement & Motivation

Despite 100% passing test suites and green benchmarks entering v0.10, physical workstation dogfooding revealed a critical product-level gap:
> On actual physical hardware, pressing `Alt+Space` failed to reliably summon a visible AstraRun interface due to Windows 11 foreground lock restrictions (`LockSetForegroundWindow`) and premature focus-loss dismissal. Furthermore, background task execution previously shared focus with the active user interface, disrupting typing flow in applications like Notepad or VS Code.

AstraRun v0.10.1 was executed to eliminate all disconnects between test reports and daily-driver product reality.

## 2. Architectural Additions in v0.10.1

### 2.1 Native Win32 Presentation Pipeline
1. **Interactive Desktop Attachment (`_ensure_desktop_attached`)**:
   - Win32 threads running in detached contexts or subshells are explicitly bound to the interactive desktop (`OpenDesktopW("Default")` -> `SetThreadDesktop`), guaranteeing that `EnumWindows`, `GetForegroundWindow`, and `RegisterHotKey` operate on the user's interactive desktop.
2. **Synchronous Origin HWND Pre-Capture**:
   - The hotkey listener thread queries and stores `GetForegroundWindow()` synchronously at the exact moment `WM_HOTKEY` is received, before any Qt window creation or focus shifting occurs.
3. **Foreground Lock Bypass (`force_foreground_activation`)**:
   - Located in `src/astrarun/ui/presentation.py`. Uses `AttachThreadInput` between the caller thread and the current foreground thread, followed by `BringWindowToTop` and `SetForegroundWindow`, ensuring the command bar is guaranteed foreground focus on Windows 11.
4. **Multi-Scale DPI Geometry & Top-Center Placement**:
   - Screen geometry mapped through `devicePixelRatio` to Qt logical coordinates (`src/astrarun/ui/positioning.py`).
   - Launcher positioned top-center of the display containing the origin window with 48px top margin.
5. **Drop-in & Slide-up Animations**:
   - Entrance: 150ms drop-in from 25px above resting position using `QEasingCurve.OutCubic`.
   - Dismissal: 110ms slide-up and fade-out using `QEasingCurve.InCubic`.
   - Dismissal guards (`_is_animating`, `_has_been_active`) prevent premature close on initial window show.

### 2.2 Decoupled Floating Task HUD (`src/astrarun/ui/hud.py`)
1. **Strict Non-Focus-Stealing Invariant**:
   - Enforced through three complementary layers:
     - Qt Window Type: `Qt.WindowType.WindowDoesNotAcceptFocus`
     - Qt Widget Attribute: `Qt.WidgetAttribute.WA_ShowWithoutActivating`
     - Win32 Extended Style: `WS_EX_NOACTIVATE = 0x08000000` via `SetWindowLongW`
2. **Top-Right Screen Positioning**:
   - Placed at top-right corner of the active monitor with 24px right and top margins.
3. **Task Event Bus Integration**:
   - `TaskHUDController` subscribes to runtime `TaskEventBus` and drives HUD state without blocking:
     - `PASSIVE_PROGRESS`: Spinning indicator, task title, dynamic status details.
     - `SUCCESS`: Green check badge, auto-dismiss timer (2.5s).
     - `ERROR`: Red alert badge, error message, auto-dismiss timer (5.0s).
     - `WAITING_CONFIRMATION`: Peach badge, non-focus-stealing confirmation action buttons.
     - `WAITING_CLARIFICATION`: Blue badge, disambiguation cards.

### 2.3 Compound NLP & Workflow Execution
1. **Clause Decomposition & Workflow Compilation**:
   - `ClauseDecomposer` extracts multi-clause actions connected by `and`, `then`, or punctuation.
   - `WorkflowCompiler` maps natural compound queries (e.g. `open notepad and type hello from Astra`) into sequential multi-step tasks (`open_app` + `type_text`).
2. **Path Auto-Resolution for Windows Applications**:
   - `open_application` in `src/astrarun/applications/service.py` auto-resolves executable paths via `find_application` and `shutil.which`, resolving modern Windows 11 packaged apps (like UWP/MSIX Notepad).

## 7. Architectural Invariants Enforced Entering v0.10.1

1. **Non-Focus-Stealing HUD Invariant**: The background progress HUD must NEVER accept or steal keyboard focus from target applications. Enforced via `Qt.WindowDoesNotAcceptFocus`, `WA_ShowWithoutActivating`, and `WS_EX_NOACTIVATE`.
2. **Synchronous Origin Pre-Capture Invariant**: The origin window HWND must be captured immediately on the hotkey listener thread before any AstraRun window is summoned or activated.
3. **Foreground Lock Bypass Invariant**: Window activation uses `AttachThreadInput` to defeat Windows 11 `LockSetForegroundWindow` restrictions.
4. **Data vs Command Separation**: Keystroke injection (`type_text`) is strictly treated as literal data, never evaluated as shell commands.
5. **Zero Raw Shell Execution**: No arbitrary shell interpolation (`shell=True`, `os.system()`, `eval()`).
