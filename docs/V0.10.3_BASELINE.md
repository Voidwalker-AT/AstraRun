## 6. Known Invariants to Preserve in v0.10.3

1. **Deterministic Fast Path (< 15 ms, p95 < 50 ms)**: Single application launches, system queries, and simple commands must bypass deep neural processing.
2. **Single Loaded Model Instance**: Laya A (pre-gate) and Laya B (post-verifier) must share the identical in-memory ModernBERT model weights. Under no circumstances may duplicate 421M weights be loaded into RAM.
3. **Payload Preservation**: User text payloads (`type <string>`) must be extracted verbatim with 100% source-span fidelity.
4. **Execution Authority Boundary**: Neural models produce linguistic structures (`ParsedRequest`, `ParsedClause`) only. Zero Win32 HWND, PID, or shell execution authority is delegated to models.
5. **Console-Free Residency**: Normal startup must result in zero persistent console or terminal processes.
