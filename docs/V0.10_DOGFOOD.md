## 1. Dogfooding Objectives & Scope

To verify AstraRun v0.10 as an unobtrusive, rock-solid daily driver capable of semantic application content manipulation without blind coordinate clicks, an intensive 30-minute resident session was conducted evaluating:
1. **Semantic UI Automation Stability**: Traversing live application element trees (Notepad, Calculator, PySide6 fixtures) via dedicated COM MTA worker threads without UI thread deadlocks.
2. **Control Mutation Invariant**: Enforcing $\text{UIA Patterns} > \text{Win32 Messages} > \text{SendInput} > \text{Permanent Coordinate Prohibition}$.
3. **Origin Window Grounding**: Interacting with active foreground application controls seamlessly when summoned via `Alt+Space`.
4. **Password Privacy & Non-Execution Invariants**: Absolute non-logging of password fields and strict treatment of text input as data rather than shell commands.
5. **Resident Resource Stability**: Long-running memory, CPU, COM handle cleanup, and thread lifecycle verification.
