QApplication Class Reference

Module: PySide6.QtWidgets Inherits: QGuiApplication Thread Safety: Main Thread Only

The QApplication class manages the GUI application's control flow and main settings. It specializes QGuiApplication with some functionality needed for QWidget-based applications. It handles widget-specific initialization, finalization, and provides the event loop that receives window system events.

Important: For any GUI application using QtWidgets, there is precisely one QApplication object, regardless of whether the application has 0, 1, 2 or more windows at any given time.

Synopsis

from PySide6.QtWidgets import QApplication, QLabel import sys app = QApplication(sys.argv) label = QLabel("Hello World!") label.show() sys.exit(app.exec())
