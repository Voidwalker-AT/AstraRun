## 2. Transition Challenge for v0.9

While all individual subsystems have achieved rigorous testing and mathematical guarantees, **the real user path from the resident UI (`Alt+Space`) is disconnected from post-v0.2 subsystems**.

The main entry point (`src/astrarun/main.py`) and UI window (`src/astrarun/ui/launcher.py`) were never updated past v0.2. They route user input exclusively through the legacy `DeterministicRouter` and legacy `ToolRegistry`.

Milestone v0.9 addresses this fundamental gap by establishing a unified Application Composition Root and a Canonical Committed-Request Pipeline, making all 47+ workstation capabilities, NLP understanding, task execution, activity timeline, history, and memory genuinely reachable in daily workstation use.
