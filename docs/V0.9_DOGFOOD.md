To ensure AstraRun v0.9 functions as a reliable, unobtrusive daily driver, a live 30-minute interactive session was performed evaluating:

3. **Multi-Monitor Window Management**: Seamless snapping across 1080p and 4K displays, DPI scaling adjustments, and geometry clamping.
4. **Memory Footprint & Leak Detection**: Resident RAM usage over 30 minutes with 50+ mixed queries and background timer ticks.
5. **UI Transition Smoothness**: Launcher modal responsiveness, card rendering transitions, and keyboard escape dismissals.

## 4. Workstation UX & Ergonomics Review

1. **Origin Window Focus Invariant**:
   - `Alt+Space` successfully captures the foreground HWND via `GetForegroundWindow()` before the PySide6 overlay asserts focus.
   - When the launcher executes a window positioning action and dismisses, focus is seamlessly restored to the targeted application via `SetForegroundWindow()`.
2. **Self-Targeting Protection (`_ASTRARUN_HWNDS`)**:
   - AstraRun never snaps, minimizes, or closes its own windows. Even if the user explicitly types `snap this window left` while AstraRun has focus, the resolver falls back to the previous origin window.
3. **Safe Window Closing**:
   - Verified that `close window` uses `PostMessageW(hwnd, WM_CLOSE, 0, 0)`, allowing applications like Notepad and VS Code to show "Save Changes?" prompts rather than forcefully killing the process.
4. **Snapping Ergonomics**:
   - Split-half and quadrant layout computations adhere strictly to `SPI_GETWORKAREA`, preserving taskbar accessibility across all monitors.
