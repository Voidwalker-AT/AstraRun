AstraRun: Autonomous Workstation Agent

AstraRun is a deterministic, closed-loop local workstation agent runtime engineered for Windows 11 systems with dedicated hardware acceleration.

Key Architecture Invariants

  • Safe Sandboxing: Windows Job Objects prevent orphan process leaks.
  • Zero Secret Plaintext: Stream scrubber redacts tokens in memory.
  • CDP Browser Integration: Native DevTools accessibility extraction.

Quick Start

astrarun --doctor
