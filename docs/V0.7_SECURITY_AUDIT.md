## 2. Invariant Verification Analysis

### Invariant 1: Zero Raw Shell Execution
- **Policy**: At no point does AstraRun construct or execute `cmd.exe /c ...`, `powershell.exe -Command ...`, `bash -c ...`, or `subprocess.Popen(..., shell=True)` with user-supplied strings.
- **Verification**: Verified via codebase AST audit and regression tests (`tests/test_security_regression.py` and `tests/test_v07_capabilities.py`). All subprocess invocations use explicit, statically validated argument lists (`["git", "branch", ...]` or `["explorer.exe", ...]`).

### Invariant 2: Hard Blocked Operations
- **Policy**: Invocations of system shutdown, reboot, raw shell execution, script file execution, or directory destruction cannot be authorized by any user prompt or router output.
- **Verification**: Evaluated in `CapabilityRegistry.execute()` and `WorkflowCompiler.compile()`. Capabilities with `CapabilityPermission.BLOCK` immediately return `PERMISSION_DENIED` with zero OS interaction.

### Invariant 3: Protected System Process Defense
- **Policy**: Critical operating system processes (`explorer.exe`, `system`, `lsass.exe`, `csrss.exe`, `services.exe`, `smss.exe`, `wininit.exe`, `dwm.exe`, `astrarun.exe`) cannot be terminated.
- **Verification**: Tested against both process name substrings and exact PID queries. `terminate_process` immediately aborts with `PERMISSION_DENIED` before any signal can be emitted.

### Invariant 4: TOCTOU-Safe Process Termination
- **Policy**: A termination signal must not be delivered if the target process has exited and its PID has been recycled by the operating system.
- **Verification**: AstraRun captures `create_time` during discovery/confirmation and re-validates that `abs(proc.create_time() - expected_time) <= 1.0` and process name matches before calling `proc.terminate()`.

### Invariant 5: Executable Script Open Prohibition
- **Policy**: Directly invoking `open_file` on script files (`.bat`, `.cmd`, `.ps1`, `.vbs`, `.js`, `.exe`, `.msi`) is prohibited to prevent drive-by code execution.
- **Verification**: Executable script extensions are intercepted with `PERMISSION_DENIED`. AstraRun suggests `reveal_file` to highlight the file in Windows File Explorer without running it.

### Invariant 6: Path Traversal Defense
- **Policy**: File queries cannot traverse outside permitted user roots using `..` or NTFS directory junctions.
- **Verification**: Path inputs are normalized with `os.path.abspath()` and verified against permitted roots. All directory walkers enforce `follow_symlinks=False`.

### Invariant 7: Command Line Sanitization
- **Policy**: Sensitive secrets (API keys, passwords, bearer tokens) must never leak into UI cards, logs, or observation stores.
- **Verification**: Process inspection runs regex filters to redact tokens (`--api-key`, `--token`, `SECRET=...`) with `[REDACTED]`.
