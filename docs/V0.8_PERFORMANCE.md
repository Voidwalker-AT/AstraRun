## 1. Workstation Test Environment
- **Host**: Windows 11 Enterprise (x64)
- **CPU**: AMD Ryzen 5 7535HS (6 Cores / 12 Threads)
- **RAM**: 16 GB DDR5
- **Storage**: Fast NVMe SSD
- **Python**: 3.13.0 (64-bit)

## 2. Large-History Scale Benchmark (10k Tasks / 100k Events)
To ensure the SQLite ledger does not degrade user interface responsiveness as history accumulates, `run_task_benchmark.py` includes a rigorous synthetic scale workload.

### Results
| Metric | Benchmark Result | Performance Target | Status |
|---|---|---|---|
| **Bulk Ingestion Speed** | **99,757 rows/sec** (1.10 s total) | > 20,000 rows/sec | **EXCELLENT** |
| **Fetch 50 Most Recent Tasks** | **1.264 ms** | < 10.0 ms | **EXCELLENT** |
| **Full-Text Substring Search (10k tasks)** | **7.429 ms** (11 matches) | < 25.0 ms | **EXCELLENT** |
| **Retention Cleanup (5,000 tasks pruned)** | **339.590 ms** | < 1,000 ms | **EXCELLENT** |

---

## 3. Operational Overhead Analysis
- **Idle Memory Footprint**: AstraRun resident memory increases by < 2.5 MB when `TaskLedger` and `TaskEventBus` are active.
- **Event Dispatch Latency**: Publishing an event to active Qt widgets via `TaskEventBus` incurs < 0.05 ms latency.
- **Disk Footprint**: 10,000 completed tasks with full event timelines consume ~14.2 MB on disk with WAL checkpointing.
