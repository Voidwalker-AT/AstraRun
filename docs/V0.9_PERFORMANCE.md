## 1. Executive Summary

To operate seamlessly as an ambient desktop daily driver, AstraRun enforces strict performance budgets:
- **Fast-Path Launcher Routing**: Budget $< 3.0\text{ ms}$ (Actual: **$0.47\text{ ms}$**).
- **Direct UI Navigation Routing**: Budget $< 1.0\text{ ms}$ (Actual: **$0.02\text{ ms}$**).
- **Win32 Window Mutations**: Budget $< 20.0\text{ ms}$ (Actual: **$0.06\text{ ms}$** for undo, **$1.8\text{ ms}$** for Win32 `SetWindowPos`).
- **Resident RAM Footprint**: Budget $< 120\text{ MB}$ (Actual: **$67.5\text{ MB}$** after 30 minutes).
- **Idle CPU Load**: Budget $< 0.1\%$ (Actual: **$0.0\%$**).

## 3. Detailed Subsystem Latency Metrics

### 3.1 Fast-Path Launcher (< 3ms Invariant)
- **Harness Verification**: Evaluated on 50 synthetic and real application queries in `Product Benchmark V1`.
- **Measured Mean Latency**: **0.4699 ms** ($p_{50}: 0.380\text{ ms}$, $p_{95}: 0.890\text{ ms}$).
- **Key Optimization**: Pure prefix matching and in-memory trie indexing bypasses heavy regex engines and spaCy pipeline invocations entirely.

### 3.2 Win32 Window Intelligence Subsystem
- **Harness Verification**: Evaluated on 330 test cases in `Window Benchmark V1`.
- **Measured Mean Latency**: **0.0229 ms** per query.
- **Window Restore Stack Pop (`undo`)**: **0.063 ms**.
- **Key Optimization**: Zero external automation processes; direct ctypes calls to `User32.dll` and `Shcore.dll`.

### 3.3 SQLite Task Ledger & Storage Engine
- **Single Task Insert**: **1.12 ms** (under SQLite `PRAGMA journal_mode = WAL` and `PRAGMA synchronous = NORMAL`).
- **Query 50 Most Recent Tasks**: **1.386 ms** across a 10,000-task database.
- **Full-Text Task Search across 10k Records**: **51.65 ms**.
- **5,000-Record Retention Purge**: **1261.2 ms**.
