# AstraRun v0.6 Performance & Latency Benchmark Report

> **Status**: MEASURED & VERIFIED  
> **Milestone**: AstraRun v0.6  
> **Hardware Host**: Windows 11, Intel Core i5-12450H @ 2.50GHz, 16GB RAM, RTX 2050  
> **Last Verified**: 2026-09-27  

---

## 1. Executive Summary

AstraRun v0.6 establishes a two-tier latency profile:
1. **Interactive Routing & Safety Gating Tier**: Operates entirely via deterministic fuzzy search, structured context resolution, and hard policy rules. It delivers **microsecond-scale responsiveness** ($0.077\text{ ms}$ mean, $p_{95}: 0.187\text{ ms}$), creating an instantaneous user interface experience.
2. **Neural Shadow Advisor Tier**: (Laya / Kev / Ensemble) Runs strictly in background shadow threads or asynchronous sidecars, completely off the hot typing path.

---

Measured across 330 end-to-end evaluation queries in Action Benchmark V1:

| Pipeline Stage | Mean Latency | Median ($p_{50}$) | 95th Percentile ($p_{95}$) | Complexity / Mechanism |

| **Deterministic Intent Inference** | $0.008\text{ ms}$ | $0.004\text{ ms}$ | $0.019\text{ ms}$ | Regex and token rule matcher |
| **Entity Resolution (`EntityResolutionEngine`)**| $0.054\text{ ms}$ | $0.016\text{ ms}$ | $0.138\text{ ms}$ | Project registry, context pronoun cache, app cache |
| **Action Gating (`ActionGate`)** | $0.015\text{ ms}$ | $0.007\text{ ms}$ | $0.030\text{ ms}$ | Hard security pre-checks, ambiguity gating, token gen |
| **Total Gated Routing Pipeline** | **$0.077\text{ ms}$** | **$0.027\text{ ms}$** | **$0.187\text{ ms}$** | Full pipeline prior to OS tool dispatch |

## 4. Latency Clarification: Decision Fusion vs. Neural Inference

As audited in `docs/V0.6_BASELINE.md`:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        LATENCY COMPARISON                              │
├────────────────────────────────┬───────────────────────────────────────┤
│ Pipeline Component             │ Wall-Clock Latency                    │
├────────────────────────────────┼───────────────────────────────────────┤
│ Deterministic Action Gate      │ 0.077 ms  (Microsecond scale)         │
│ Decision Fusion Math (E0-E5)   │ 0.040 ms  (Numpy array computation)   │
│ Batched Laya CPU Inference     │ 227.0 ms  (Optimized batch forward)   │
│ Live Single-Query Laya CPU Pass│ 1,200 - 1,800 ms (Single PyTorch pass)│
└────────────────────────────────┴───────────────────────────────────────┘
```

> [!IMPORTANT]
> The $0.077\text{ ms}$ pipeline latency allows AstraRun to evaluate every keystroke in real-time. Because neural models require $> 1,000\text{ ms}$ per single query on CPU, **neural execution authority is strictly prohibited on the interactive path**. Neural models remain shadow advisors.
